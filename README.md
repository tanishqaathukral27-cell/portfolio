# Personal Portfolio Website

A personal page telling who I am, my achievements, my likes and dislikes, and showcasing my personality.

## Overview

I built this website to have a little space where my personality comes together and a page that shows who I am.

## Features

* Personal information
* Achievements
* Interests and hobbies
* Responsive and engaging layout
* Custom visual design
* Typography
* Interactive elements

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Git and GitHub
* Vercel for deployment

## Project Structure

```text
portfolio/
├── images/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Running Locally

1. Clone the repository.
2. Open the project in VS Code.
3. Start a local development server.
4. Run the website.
