# Personal Portfolio — Tanishqaa

A personal portfolio website showcasing my background, interests, creative work, projects, and achievements.

## Overview

This website is designed as a personal space on the web rather than a conventional portfolio. It combines an editorial-inspired layout with subtle whimsical elements to create a distinctive and personal experience.

The site will continue to evolve as I add new projects, writing, experiences, and experiments.

## Features

* Personal introduction and background
* Projects and achievements
* Creative interests and hobbies
* Responsive layout
* Custom visual design and typography
* Interactive elements using JavaScript
* Personal domain deployment

## Tech Stack

* **HTML5** — Structure and content
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript** — Interactivity and dynamic behavior
* **Vercel** — Deployment
* **Git & GitHub** — Version control

## Development

To run the website locally:

1. Clone the repository.
2. Open the project in VS Code.
3. Start a local development server such as Live Server.
4. Open the provided local URL in your browser.
